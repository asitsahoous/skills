---
name: product-discovery
description: A specialized, high-reliability skill for product discovery. The assistant will execute a deep-dive product discovery process by analyzing the product's description and user reviews. It will:
1. Identify the core problem the product solves.
2. Determine the target user segment.
3. Detect existing user pain points.
4. List current workarounds users employ.
5. Uncover unmet needs and desires.
6. Generate innovative product ideas to address these needs.
7. Evaluate idea feasibility and market potential.
8. Produce a structured Product Discovery Report including Problem Statement, Target Users, User Personas, Pain Points, Current Solutions/Workarounds, Unmet Needs, Generated Ideas, and Recommendations.
